# Kal'tsit's Warp-Modification Plan

## This project is for users who are temporarily unable to provide the Wuling DevOps plugin or do not want to change their editor.

Of course, a VS Code plugin is out of the question; otherwise, no one would use Logos, Zed, etc. We'll have to wait for the official API release, or submit a pull request to add an API ourselves.

Stage 1：First, change the theme and add our SSO account.

Stage 2：Change the AI ​​orchestration backend to Wuling DevOps

Stage 3：Add a complete set of WebRTC endpoints (video, audio, screen sharing) provided by Wuling DevOps.

Stage3.5：Add a read-only buffer that allows you to view what teammates are editing in the meeting room, a terminal, and a debug console (and add "Open in Logos for write capability").

Stage 4: Add "Anti-Cat Mode" (to prevent embarrassing situations caused by accidental activation of the camera and microphone).

Stage 5: Add prompts such as "Connected", "Not Connected", and "Poor Network Quality".

Stage 6：Deep integration with Wuling DevOps
